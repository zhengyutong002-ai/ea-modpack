# 乖離剣エア × Rising Legends 2 インストールガイド

このパックは **Rising Legends 2**（RLCraft 2）に **乖離剣エア** を追加したものです。
一度インストールすれば、ゲームを起動するたびに乖離剣エアが自動でアップデートされます。

## 必要なもの
- **Minecraft Java 版（正規版）** を購入した Microsoft アカウント
- Windows 10 / 11（64 ビット）、メモリ 16 GB 以上がおすすめ
- 空き容量 5 GB 以上

## インストール（かんたん）
1. このリンクから `install.bat` をダウンロードします：
   https://github.com/zhengyutong002-ai/ea-modpack/releases/latest/download/install.bat
   - ブラウザに「一般的にダウンロードされていません」と出たら「保存」→「保持する」を選んでください。
2. ダウンロードした `install.bat` をダブルクリックします。
   - 「Windows によって PC が保護されました」と出たら「詳細情報」→「実行」を押してください。
3. 画面の指示に従って待ちます（10〜30 分ほど）。自動で次のことをします：
   - Prism Launcher のインストール
   - Rising Legends 2 1.2 のダウンロード（Modrinth から）
   - 乖離剣エアの自動アップデート設定、メモリ 6 GB の設定
4. 「インストール完了」と出たら：
   1. スタートメニューから **Prism Launcher** を開く（初回は言語を選んで「次へ」、Java は自動ダウンロードで OK）
   2. 右上の「アカウント」から Microsoft アカウントでログイン
   3. **Rising Legends 2** をダブルクリックして起動
   - 初回起動では Minecraft 1.21.1・NeoForge・乖離剣エアなどを自動でダウンロードするので、しばらくかかります。

うまくいかないときは、エラー画面のスクリーンショットを送ってください。

## みんなで遊ぶ（playit.gg）
ホスト（ワールドを開く人）だけが準備します。参加する人は何もインストール不要です。

**ホスト：最初の 1 回だけ**
1. https://playit.gg から Windows 版をダウンロードしてインストールし、起動して画面の指示どおりログイン（無料）。
2. playit のサイトで「Add Tunnel」→ 種類は **Minecraft Java** → ローカルポートは **25565** → 作成。
   固定のアドレス（例：`xxxx.joinmc.link`）がもらえます。次回からもずっと同じアドレスです。

**毎回**
- **ホスト**：playit を起動しておく → シングルプレイのワールドに入る → Esc →「LAN に公開」→ ポート番号に **25565** を入力 →「LAN ワールドを公開」。アドレスを友達に送ります。
- **参加する人**：マルチプレイ →「サーバーを追加」（または「ダイレクト接続」）→ ホストのアドレスを入力 → 参加。
- ホストがゲームか playit を閉じると、ほかの人は入れなくなります。

## よくある質問
- **「バージョンが違う / モッドが足りない」と出る**：全員が一度ゲームを再起動すると、乖離剣エアが最新版にそろいます。
- **シェーダー（Iris）をオンにすると乖離剣エアのエフェクト（ゆがみ・ひび割れ）が見えない**：シェーダーをオフにしてください。
- **重い・固まる**：ほかのアプリを閉じて、ビデオ設定で描画距離を 8 くらいに下げてください。
